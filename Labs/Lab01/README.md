# Lab 02: Cortical Column Voting Simulation

## Overview
This lab explored how multiple simplified cortical columns can reach consensus through a voting mechanism inspired by the Thousand Brains Theory.

## What I Did
- Implemented multiple simulated columns
- Created partial sensory evidence
- Applied a voting mechanism across columns
- Visualized consensus formation over time
- Ran experiments with noise, column count, and vote weight

## What I Learned
I learned that distributed systems can become more robust by combining partial information from multiple sources. I also observed that consensus mechanisms involve trade-offs between speed and accuracy.

## Challenges
The most challenging part was understanding how vote weight affects whether the system relies more on individual evidence or group consensus.
