# Assignment 04: Exploring Spiking Neurons with Wolfram

## Problem
This assignment explored how a Leaky Integrate-and-Fire neuron can be modeled using Wolfram Language.

## Approach
I used `NDSolve` and `Manipulate[]` to simulate membrane potential, threshold firing, reset behavior, and firing-rate curves.

## Results
The simulation showed how input current, firing threshold, and membrane time constant affect whether and how often a neuron spikes.

## What I Learned
I learned that even a simplified neuron model can demonstrate important biological principles such as leak, integration, threshold crossing, and spike timing.
